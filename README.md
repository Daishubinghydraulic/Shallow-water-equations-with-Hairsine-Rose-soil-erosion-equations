This code is written by VBA in Excel based on the code in the textbook <Shallow water hydraulics> by Prof. Oscar Castro-Orgaz and Prof. Willi H. Hager. We implemented Hairsine-Rose equations for soil erosion modelling on hillslope. 
This is an attached code for the manuscript "Roll-Wave Evolution in Sediment-Laden Overland Flow Using a Coupled Shallow-Water–Sediment Model" submitted to Water Resources Research.
